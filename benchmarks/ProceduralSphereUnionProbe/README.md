# Procedural sphere-union probe

Run `LC_ALL=C dotnet run --project benchmarks/ProceduralSphereUnionProbe -c Release`. The probe builds 20 procedural ball sets (collinear pairs and a chain with analytic volume and area, exact tangency, gaps and overlaps down to `1e-12`, a coplanar 6-ball ring, tetrahedral and octahedral cavity clusters, 16- and 32-ball helices and seeded 12- to 96-ball multi-radii packings) from `Sphere3Generator_NormalizedCube` meshes and unites them with `ExactMeshBoolean` (multi-mesh and binary tree), `SolidBooleanPipeline`, `MarchingCubes` on the union implicit and `MeshAlphaWrap`. It prints one row per case and route: status, `MeshRobustRepair.NotCleanReason`, triangle, component, boundary-edge and bowtie counts, Euler characteristic, volume and area (relative errors where an analytic value exists) and wall time. No mesh files are read or written. Results and conclusions: [docs/research/MOLECULAR_SURFACES_STUDY.md](../../docs/research/MOLECULAR_SURFACES_STUDY.md). Times are single runs and vary between runs.

## Scaling and hybrid modes (#1466)

`dotnet run --project benchmarks/ProceduralSphereUnionProbe -c Release -- scaling [reps] family:n,n,...` runs the multi-mesh union and the pairwise tree of each family (`denseSEED` = the random packing with that seed, nested by size, `helix`, `lattice`) alternately `reps` times and prints one `RAW` line per run with the public `PhaseMilliseconds` and `Counts` (tree: summed over its unions), the patch count, the result's volume and area (x 1e9) and a hash of the result's vertices and triangles; `clean` (1 = closed and `MeshRobustRepair.NotCleanReason(mesh, checkSelfIntersections: true)` empty; otherwise a `CLEAN NOT <reason>` line is printed; `hybrid` too); `INFO` lines give the overlap degree of the balls. `G3_ROUTES=multi` skips the tree. `DOTNET_PROCESSOR_COUNT=n` restricts the core count. `hybrid [reps] idx|morton family:n:g,g,...` unites groups of `g` bodies in one arrangement each, then a pairwise tree of the group results. `python aggregate_scaling.py results/<file> [key ...]` prints medians and ranges. Raw results: `results/` (`scaling_2026-11-24_quiet_timing_raw.txt` is the timing reference of the quiet run and predates the volume, area, hash and clean fields; `scaling_2026-11-24_checks_raw.txt` has them, with the loaded timings not to be used; `scaling_2026-11-24_loaded12_raw.txt` and `_loaded4_raw.txt` (`DOTNET_PROCESSOR_COUNT=4`) are loaded-machine data points;  `hybrid_raw.txt`, `ub_winding_raw.txt`, `diag_instrumented_raw.txt` and `instrumentation_1466.patch`, the throwaway library edit behind the `x_*` counters and the `G3_UB` modes). Analysis: [docs/research/NARY_UNION_DENSE_2026-11.md](../../docs/research/NARY_UNION_DENSE_2026-11.md). User-facing rule (one call or a tree, by overlap degree): [Union of many overlapping bodies](../../docs/guides/booleans-and-imprint.md#union-of-many-overlapping-bodies-one-call-or-a-tree).
