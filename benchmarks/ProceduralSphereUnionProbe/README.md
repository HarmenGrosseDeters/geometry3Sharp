# Procedural sphere-union probe

Run `LC_ALL=C dotnet run --project benchmarks/ProceduralSphereUnionProbe -c Release`. The probe builds 20 procedural ball sets (collinear pairs and a chain with analytic volume and area, exact tangency, gaps and overlaps down to `1e-12`, a coplanar 6-ball ring, tetrahedral and octahedral cavity clusters, 16- and 32-ball helices and seeded 12- to 96-ball multi-radii packings) from `Sphere3Generator_NormalizedCube` meshes and unites them with `ExactMeshBoolean` (multi-mesh and binary tree), `SolidBooleanPipeline`, `MarchingCubes` on the union implicit and `MeshAlphaWrap`. It prints one row per case and route: status, `MeshRobustRepair.NotCleanReason`, triangle, component, boundary-edge and bowtie counts, Euler characteristic, volume and area (relative errors where an analytic value exists) and wall time. No mesh files are read or written. Results and conclusions: [docs/research/MOLECULAR_SURFACES_STUDY.md](../../docs/research/MOLECULAR_SURFACES_STUDY.md). Times are single runs and vary between runs.
