# Neuron skeleton probe

Run `LC_ALL=C dotnet run --project benchmarks/NeuronSkeletonProbe -c Release`. The probe builds 9 procedural SWC-style skeletons (forks down to `4°`, two branches whose meshes are `1e-2` and `1e-6` apart, an intentional loop, and bifurcating trees of 21, 25 and 45 segments) as tapered `CappedCylinderGenerator` frusta with `Sphere3Generator_NormalizedCube` joint spheres, and closes each with multi-mesh and binary-tree `ExactMeshBoolean`, `SolidBooleanPipeline`, `MarchingCubes` on a Cauchy-kernel convolution field and `MeshAlphaWrap`. It prints one row per case and route (status, `MeshRobustRepair.NotCleanReason`, triangles, components, boundary edges, bowties, Euler characteristic, genus, volume, wall time; `*` marks a topology mismatch against the expected one), then the measured mesh clearances per case. No mesh files are read or written. Results and conclusions: [docs/research/NEURON_SKELETON_MESHES.md](../../docs/research/NEURON_SKELETON_MESHES.md). Times are single runs and vary between runs.
