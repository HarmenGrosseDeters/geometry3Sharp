// Banned APIs for the exact-arithmetic code (Microsoft.CodeAnalysis.BannedApiAnalyzers, rule RS0030).
// The rule is an error only in the exact-arithmetic files listed in .editorconfig and off everywhere else. It has no
// allow-list. Format: documentation comment ID;message
// (https://github.com/dotnet/roslyn-analyzers/blob/main/src/Microsoft.CodeAnalysis.BannedApiAnalyzers/BannedApiAnalyzers.Help.md)
// The analyzers in tools/analyzers/G3ExactCodeAnalyzers cover what this list cannot: every float type (G3E0001),
// parallel loops with their allow-list (G3E0002) and fused multiply-add by name, in any type (G3E0003).

// fused multiply-add rounds once instead of twice: the error-free transformations and the filter bounds assume
// separately rounded products and sums (G3E0003 also catches the ones not listed here)
M:System.Math.FusedMultiplyAdd(System.Double,System.Double,System.Double);exact code: FMA changes the rounding the error bounds assume
M:System.Double.FusedMultiplyAdd(System.Double,System.Double,System.Double);exact code: FMA changes the rounding the error bounds assume
M:System.Double.MultiplyAddEstimate(System.Double,System.Double,System.Double);exact code: FMA changes the rounding the error bounds assume
// no hardware intrinsics in exact code (they contain FMA)
N:System.Runtime.Intrinsics.X86;exact code: no hardware intrinsics (FMA changes the rounding the error bounds assume)
N:System.Runtime.Intrinsics.Arm;exact code: no hardware intrinsics (FMA changes the rounding the error bounds assume)

// single precision: the bounds are derived for double (eps = 2^-53); G3E0001 also catches declarations, casts,
// literals and float structs
T:System.Single;exact code: no float, the error bounds are derived for double
T:System.MathF;exact code: no single-precision math

// lock-free floating-point accumulation across threads depends on the schedule
M:System.Threading.Interlocked.Exchange(System.Double@,System.Double);exact code: floating-point accumulation across threads is not deterministic
M:System.Threading.Interlocked.CompareExchange(System.Double@,System.Double,System.Double);exact code: floating-point accumulation across threads is not deterministic
M:System.Threading.Interlocked.Exchange(System.Single@,System.Single);exact code: floating-point accumulation across threads is not deterministic
M:System.Threading.Interlocked.CompareExchange(System.Single@,System.Single,System.Single);exact code: floating-point accumulation across threads is not deterministic
