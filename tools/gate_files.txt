# Gate files: files that define or run the checks that judge a pull request (docs/QA.md, "Gate-change check").
# A PR that changes one of them needs the label `gate-change` (set by the owner only), so a change cannot loosen its own checks.
# Format: one `glob | reason` per line; `#` starts a comment line. Globs match the whole repository-relative path:
# `*` and `?` stay inside one path segment, `**/` matches any number of directories (also none), a trailing `/**` matches everything below.
# The check reads this file from the BASE branch (.github/workflows/gate-change.yml), so a PR cannot edit its own list.

# --- the check itself
tools/gate_files.txt | this list
tools/gate_check.py | the script that applies this list
tools/test_gate_check.py | the tests of that script
.github/workflows/** | every workflow: what runs, with which thresholds, on which triggers, and the gate-change check
.github/copilot-instructions.md | agent instructions (bind agents like CLAUDE.md)

# --- rules for agents and reviews
CLAUDE.md | binding project rules (test time, test requirements, review, merge gates)
AGENTS.md | agent rules
docs/AGENT_WORKFLOW.md | merge, review and cost rules
docs/REVIEW_CHECKLIST.md | the checklist every review uses

# --- build-time rules that fail the build
.editorconfig | analyzer severities and the list of exact files (G3E/G3D analyzers)
addons/**/.editorconfig | analyzer severities of the add-ons
BannedSymbols.txt | banned APIs in the exact code
DeterministicApis.txt | allow list of the determinism proof scope
core/ExactCodeAllowList.cs | parallel loops allowed in the exact code
tools/analyzers/** | the analyzers G3E0001-3 and G3D0001-9
geometry3Sharp.csproj | wires analyzers, banned symbols and package validation
geometry3Sharp_netstandard.csproj | wires analyzers, banned symbols and package validation (dotnet pack)
CompatibilitySuppressions.xml | intentional API breaks against 1.0.324
**/CompatibilitySuppressions.xml | intentional API breaks (any project)
.config/dotnet-tools.json | the versions of the tools CI runs (Stryker.NET)

# --- test-time rule, time-rule job inputs
tests/geometry3Sharp.Tests/SLOW_BACKLOG.txt | tests allowed above 5 s (may only shrink)
tools/*.py | CI scripts and their tests (scope, trx durations, new tests on base, changed-line coverage, schedule guard, runtime watch)
tools/runtime-watch/** | cases of the runtime watch (nightly extreme cases)
tools/coverage/** | mutant coverage checks and their unmeasurable-line list and validation data
tests/coverage.runsettings | coverage collection settings

# --- mutation testing

tests/mutation/*.ps1 | mutation run scripts
tests/mutation/*.runsettings | mutation coverage selection settings

tests/mutation/test-filters/** | the tests each shard runs
